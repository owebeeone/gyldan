The license grants rights to use, study, modify and redistribute the covered
work under its terms. Distribution of covered binaries carries obligations to
provide their corresponding source through a method permitted by the license.
Keep license and copyright notices with copies you distribute.

Read the project's [license](https://github.com/owebeeone/gyldan/blob/main/LICENSE)
and [copyright scope](https://github.com/owebeeone/gyldan/blob/main/COPYRIGHT), and
the [GNU GPL version 3 text](https://www.gnu.org/licenses/gpl-3.0.html) for the
complete terms.

## Third-party components

Third-party libraries and runtime dependencies retain their own licenses and
notices. The installed wheel includes native validator notices under
`gyldan_validator/licenses`. Additional installed dependencies include their own
package metadata and license files.

The `sources.lock.json` file identifies the exact first-party component
revisions used to build a release. The license applies to those covered
components as well as the release tooling.

## Release source access

Consult each release's files and notices for its corresponding source and
build information. The current release workflow builds binary wheels and
checksums from pinned component repositories. Public corresponding-source
packaging and its release links remain release work. Source access for a
distributed GPL binary must be supplied under the license's terms.
